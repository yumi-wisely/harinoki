# お知らせの更新マニュアル(かんたん版)

サイトの「お知らせ」は、**1つのファイルに1件書き足すだけ**で更新できます。
書き足すと、サイト上の次の3か所が自動で変わります。

- トップページの「お知らせ」一覧(最新3件)
- 画面上部の、左に流れるお知らせの帯(最新3件)
- お知らせ一覧ページ(全件)

所要時間は約5分です。パソコンで行ってください。

---

## はじめに必要なもの

- GitHub(ギットハブ)にログインできるアカウント(サイトの編集権限があるもの)
- パソコン

---

## 全体の流れ

1. 編集ページを開く
2. お知らせを1件コピーして書き換える
3. 保存する(Commit)
4. 1〜2分後にサイトで確認する

---

## 手順1:編集ページを開く

GitHubにログインした状態で、次のリンクをクリックします。

**https://github.com/yumi-wisely/harinoki/edit/main/js/news-data.js**

文字を書き換えられる画面が開けばOKです。

---

## 手順2:お知らせを1件追加する

画面の上のほうに、次のような `{ }` で囲まれたかたまりが並んでいます。
これが「お知らせ1件分」です。

```
window.NEWS_ITEMS = [
  {
    id: 3,
    date: "2026.08.20",
    tag: "お知らせ",
    title: "プレオープンのお知らせ",
    body: "鍼ノ木は、まもなくプレオープンを迎えます。…"
  },
  {
    id: 2,
    ...
  }
];
```

### 追加のしかた

1. `window.NEWS_ITEMS = [` と書いてある行の**すぐ下の行の先頭**をクリックします
2. 下の「コピー用」をコピーして、そこに貼り付けます
3. 日付・タイトル・本文を書き換えます

**コピー用**

```
  {
    id: 4,
    date: "2026.10.15",
    tag: "お知らせ",
    title: "ここにタイトルを書く",
    body: "ここに本文を書く"
  },
```

### 書き換える項目

| 項目 | 書くこと | 例 |
|---|---|---|
| id | **今ある番号より大きい数字**(他と同じ番号にしない) | 前回が `3` なら `4` |
| date | 日付を `年.月.日` で | `"2026.10.15"` |
| tag | `"お知らせ"` か `"コラム"` | `"コラム"` |
| title | お知らせのタイトル | `"年末年始の営業日について"` |
| body | 本文 | `"年末は12月30日まで営業いたします。"` |
| image | **写真を入れるときだけ**書く(入れないときは、この行ごと書かない)。やり方は下の「写真を入れたいとき」を見てください | `"assets/news/2026-10-15-open.jpg"` |

### 書き換えるときのルール(ここだけ守れば大丈夫です)

- 書き換えてよいのは、**`" "`(ダブルクォーテーション)の中の文字だけ**です。`"` や `,` や `{ }` は消さないでください
- 1件ごとのかたまりの**最後の `,`(カンマ)は必ず残して**ください
- 本文の途中で**段落を変えたいとき**は `\n` と書きます(`\n` の部分は表示されず、改行になります)
  - 例:`body: "1段落目の文章です。\n2段落目の文章です。"`
- 本文やタイトルの中で `"`(半角のダブルクォーテーション)は使えません。強調したいときは「 」を使ってください
- `"` や `,` は**半角**で入力します(全角の `“ ”` や `、` にしない)

### 追加後のイメージ

```
window.NEWS_ITEMS = [
  {
    id: 4,
    date: "2026.10.15",
    tag: "お知らせ",
    title: "年末年始の営業日について",
    body: "年末は12月30日まで営業いたします。\n年始は1月6日からです。"
  },
  {
    id: 3,
    date: "2026.08.20",
    ...
```

並び順は日付の新しい順に自動で整うので、貼り付ける位置を少しまちがえても大丈夫です。

---

## 手順3:保存する

1. 画面の右上にある、緑色の **「Commit changes...」** ボタンを押します
2. 小さな画面が開くので、もう一度、緑色の **「Commit changes」** ボタンを押します
   (入力欄は、そのままで大丈夫です。書きたければ「お知らせ追加」などと入れてください)

これで保存は完了です。

---

## 手順4:サイトで確認する

保存してから**1〜2分ほど待って**、サイトを開きます。

**https://harinoki.vercel.app/**

- 画面上部の流れる帯と、トップの「お知らせ」に新しいお知らせが出ていればOKです
- すぐに変わらないときは、ページを再読み込みしてください(パソコン:`Ctrl + R`、Macは `Command + R`)

---

## 写真を入れたいとき

お知らせの記事に、写真を1枚入れることができます。
写真は、**お知らせ一覧ページ**の記事の本文の下に表示されます(トップの一覧と流れる帯には出ません)。

「写真を保存する」→「お知らせに写真を書き足す」の**2段階**で行います。必ず、この順番で行ってください。

### 写真の準備(アップロードする前に)

スマホやカメラの写真は、そのままだと大きすぎて、サイトの表示が遅くなります。次のように準備してください。

- **大きさ**:横幅 **1200px くらい**、ファイルの大きさは **1MB 以下**が目安です
  - Macの場合:写真をダブルクリックして「プレビュー」で開き、メニューの「ツール」→「サイズを調整」で、幅を `1200` にして保存します
  - Windowsの場合:写真を右クリック→「プログラムから開く」→「ペイント」で開き、「サイズ変更」で、横を `1200` ピクセルにして保存します
- **ファイルの名前**:**半角の英数字**にします。日本語・スペースは使わないでください
  - 良い例:`2026-10-15-open.jpg`
  - 悪い例:`写真 1.jpg`、`IMG 0001.JPG`
- **種類**:`.jpg` か `.png` にしてください

### ステップ1:写真を保存(アップロード)する

1. 次のリンクを開きます(GitHubにログインした状態で)
   **https://github.com/yumi-wisely/harinoki/upload/main/assets/news**
2. 画面の枠(「Drag files here …」と書いてある所)に、準備した写真を**ドラッグして入れます**(「choose your files」をクリックして選んでもOK)
3. 写真の名前が下に出たら、画面の下のほうにある、緑色の **「Commit changes」** ボタンを押します

### ステップ2:お知らせに写真を書き足す

手順2のお知らせに、`image:` の行を1行足します。
**`body` の行の最後に `,`(カンマ)を付けるのを忘れないでください。**

```
  {
    id: 4,
    date: "2026.10.15",
    tag: "お知らせ",
    title: "ここにタイトルを書く",
    body: "ここに本文を書く",
    image: "assets/news/2026-10-15-open.jpg"
  },
```

- `image:` の後ろの `"assets/news/` までは、そのまま書きます
- その後ろの**ファイル名**は、ステップ1でアップロードした写真の名前と、**一字一句同じ**にします(大文字・小文字も同じにしてください)
- `image` の行が、そのお知らせの**最後の行**になるので、`image` の行の最後には `,` を**付けません**

書いたら、手順3(保存)と手順4(確認)を行います。

### 写真がうまく表示されないとき

- お知らせの文章は出るのに、**写真だけ出ない** → ほとんどの場合は、ファイル名のまちがいです。ステップ1でアップロードした写真の名前(`.jpg` と `.jpeg` のちがい、大文字・小文字も)と、`image:` に書いた名前を見比べてください
- ステップ1の保存(Commit)を忘れていないかも確認してください
- 写真は、アップロードしてから表示されるまでに1〜2分かかることがあります

---

## お知らせを消したいとき

消したいお知らせの `{` から `},` までを、**まるごと**削除して、手順3の保存をします。

古いお知らせは、**消さなくてもかまいません**。トップと帯には自動で最新3件だけが表示され、お知らせ一覧ページには全件が残ります。

## お知らせの文章を直したいとき

手順1の編集ページを開き、直したい文字を書き換えて、手順3の保存をします。

---

## うまくいかなかったとき

**お知らせが全部消えた・表示がおかしい**

ほとんどの場合、`"`(引用符)や `,`(カンマ)の消し忘れ・入れ忘れが原因です。次の点を確認してください。

- 各項目の最後に `,` があるか(ただし、そのお知らせの**いちばん最後の行**だけは `,` がなくて正しいです。写真なしなら `body` の行、写真ありなら `image` の行です)
- 各 `{ }` のかたまりの最後に `,` があるか
- `"` が2つ1組になっているか(片方だけになっていないか)
- 全角の `“ ”` を使っていないか

見つからないときは、**今あるほかのお知らせと見比べて**、同じ形になっているか確認してください。それでも直らないときは、管理者に連絡してください。

**保存(Commit)する前に画面を閉じてしまった**

保存していなければ、サイトは何も変わりません。もう一度、手順1からやり直してください。
